description: High-traffic configuration keys at a glance.

| Key | Default idea |
|-----|----------------|
| `auth.provider` | `none` \| `keycloak` |
| `auth.useMockAuth` | Mock IdP for Playwright |
| `auth.session.idleTimeoutMs` | `0` = stay signed in |
| `auth.disabledAccount.enabled` | Overlay pack off by default |
| `iam.enabled` | User management overlay |
| `ui.formMode` | `sidebar` \| `page` |
| `ui.searchMode` | `field` \| `global` |
| `fuse.theme.primary` | `#791EFF` |
| `output.overwritePolicy` | `overwrite` / `merge` / … |
| `proxy.write` | `both` \| `prod` \| `dev` |
