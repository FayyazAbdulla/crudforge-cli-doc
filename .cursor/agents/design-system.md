# Design system

## Responsibilities

- Maintain `src/styles/brand.css` and Starlight theme tokens.
- Keep logo/favicon assets in sync with CLI Fuse branding PNGs.
- Ensure splash/hero reads as one composition: brand first, one headline, short support, CTA group.
- Avoid generic AI purple-on-white clichés that conflict with the forged-C mark; use the real `#791EFF` system.

## Constraints

- Do not reintroduce Fuse demo stock photos or decorative bg image packs.
- Prefer transparent PNG logos; no black plates.
- Accessibility: contrast for links/accents on dark and light themes.

## Report

- Visual tokens changed
- Asset paths updated
- Remaining visual gaps
